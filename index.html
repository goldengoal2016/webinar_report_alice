Правила подсчёта
  • GetCourse. Регистрации и оплаты интенсива учитываются по 19 ноября включительно. Формы входа — завершённые заказы «Вход - День 1», «Вход - День 2» и «Вход - День 3» за соответствующую дату. Повторные записи одного контакта объединены.
  • Bizon. Комнаты formula_love_1, formula_love_2, formula_love_3. Просмотр — больше 0 секунд. Людей объединяем по точному совпадению почты, телефона или lead_id. Анонимные подключения без совпадающих идентификаторов учтены отдельно. API не передаёт роль участника в строках просмотров.
  • Боты. Тестовые аккаунты исключены. Кодовое засчитывается один раз на аккаунт, день и слово. Задания и ключи за день считаются по календарной дате действия. Книга за присутствие выдаётся за второе слово в эфирное окно.
  • Анкеты. Открытие считаем по подтверждённой отправке первого вопроса ботом. Заполнение — по сохранённым ответам на все вопросы. Заказ подтверждён, когда сохранён его ID и сверены поля GetCourse.
  • Коммерческие метрики. События разделены по фактическим стартам эфиров. Третий период заканчивается на срезе GetCourse. Полная или частичная оплата «Метода» учитывается по правилам отчёта отдела продаж. Брони вынесены отдельной строкой.
