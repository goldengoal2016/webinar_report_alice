Правила подсчёта
  • GetCourse. Регистрации берём по оплачиваемому интенсиву и бесплатному доступу. Формы входа — завершённые заказы «Вход - День 1» и «Вход - День 2» за соответствующую дату. Повторные записи одного контакта объединены.
  • Bizon. Комнаты formula_love_1 и formula_love_2. Просмотр — больше 0 секунд. Людей объединяем по точному совпадению почты, телефона или lead_id. Анонимные подключения без совпадающих идентификаторов учтены отдельно. API не передаёт роль участника в строках просмотров.
  • Боты. Тестовые аккаунты исключены. Кодовое засчитывается один раз на аккаунт, день и слово. Задания и ключи за день считаются по календарной дате действия. Книга за присутствие выдаётся за второе слово в эфирное окно.
  • Коммерческие метрики. Для первого дня окно от старта первого эфира до старта второго, для второго — до среза. Оплата «Метода» считается по правилу отчёта отдела продаж.
